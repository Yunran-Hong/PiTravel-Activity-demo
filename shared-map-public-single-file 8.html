榜单规则

  • 活动包含四个榜单：全部热榜、暑期玩法、本地玩乐、抽象地图榜。
  • 每个榜单展示今日热度最高的 Top20 地球角落。
  • 地图热度由今日内有效浏览、收藏、分享、好友进入、点位补充等行为综合计算。
  • 每日热榜每天更新。
  • 奖励不每天发，而是每周统一统计日榜上榜记录并结算。
  • 各榜单 Top10 创作者可获得完整地图冰箱贴套装。
  • 各榜单 Top11-20 创作者可获得单个地图碎片冰箱贴。
  • 完整套装每个用户活动期间最多领取一次，单片冰箱贴可继续获得。
